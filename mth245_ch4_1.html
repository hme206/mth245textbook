Chapter 4: Pictures of Data

Section 4.1: Introduction

Overview

Statistics provides tools for organizing, summarizing, and communicating information contained in data. When a data set contains many observations, individual values can be difficult to interpret and important patterns may be hidden. Frequency distributions and graphical displays organize the data so that patterns, comparisons, trends, and unusual features are easier to recognize.

A graph describes the data that were collected. It does not, by itself, determine whether the data represent the larger population. A misleading sample can produce a misleading graph even when the graph is constructed correctly.

Learning Objectives

After completing this chapter, you should be able to:

  • Construct frequency distributions for categorical and quantitative data.
  • Determine class widths, class limits, and class boundaries for grouped data.
  • Calculate and interpret frequency, relative frequency, cumulative frequency, and cumulative relative frequency.
  • Construct and interpret bar charts and histograms.
  • Distinguish between bar charts and histograms and identify when each is appropriate.
  • Describe the shape of a distribution using terms such as symmetric, positively skewed, negatively skewed, uniform, unimodal, bimodal, and multimodal.
  • Identify and investigate potential outliers in a data set.
  • Construct and interpret Pareto charts, circle graphs, and time-series graphs.
  • Construct and interpret stem-and-leaf plots while preserving the original observations.
  • Use frequency distributions and graphical displays to identify patterns, trends, clusters, gaps, and unusual observations in data.
