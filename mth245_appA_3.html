Appendix A: Technology

Section A.3: TI-84 Graphing Calculator

The TI-84 graphing calculator includes built-in statistical functions for one-variable statistics, two-variable statistics, correlation, and linear regression. Before beginning, it is good practice to clear any existing lists.

Entering Data

  1. Press STAT.
  2. Select 1:Edit… and press ENTER.
  3. Enter the explanatory variable values into list L1.
  4. Enter the response variable values into list L2. For one-variable statistics, only L1 is needed.

Summary Statistics

To compute summary statistics such as the mean, standard deviation, and quartiles:

  1. Press STAT.
  2. Move to the CALC menu.
  3. Select 1:1-Var Stats.
  4. Enter L1 (usually by pressing 2ND 1).
  5. Press ENTER.

The calculator displays:

  • \(n\) — number of observations,
  • \(\bar{x}\) — sample mean,
  • \(\Sigma x\) — sum of the observations,
  • \(\Sigma x^2\) — sum of the squared observations,
  • \(S_x\) — sample standard deviation,
  • \(\sigma_x\) — population standard deviation,
  • \(\min X\) — minimum value,
  • \(Q_1\) — first quartile,
  • Med — median,
  • \(Q_3\) — third quartile,
  • \(\max X\) — maximum value.

The sample variance is \(S_x^2\), and the population variance is \(\sigma_x^2\).

Scatter Plots

To display a scatter plot:

  1. Press 2ND Y= (STAT PLOT).
  2. Select Plot1.
  3. Turn the plot On.
  4. Choose the scatter plot icon.
  5. Set Xlist to L1.
  6. Set Ylist to L2.
  7. Press ZOOM.
  8. Select 9:ZoomStat.

Correlation and Regression

By default, many TI-84 calculators do not display the correlation coefficient. To enable it:

  1. Press 2ND 0 (CATALOG).
  2. Scroll to DiagnosticOn.
  3. Press ENTER twice.

This setting only needs to be enabled once unless the calculator memory is reset.

To compute the least squares regression line:

  1. Press STAT.
  2. Move to the CALC menu.
  3. Select 4:LinReg(ax+b) (or 8:LinReg(a+bx), depending on the calculator's settings).
  4. Enter L1,L2 using 2ND 1, ,, and 2ND 2.
  5. Press ENTER.

The calculator reports:

  • the slope,
  • the intercept,
  • Pearson's correlation coefficient, \(r\) (if diagnostics are enabled),
  • the coefficient of determination, \(R^2=r^2\).

To display the regression line together with the scatter plot:

  1. At the end of the LinReg command, append ,Y1 by pressing VARS, selecting Y-VARS, then Function, and finally Y1.
  2. Press ENTER. The regression equation is stored in Y1.
  3. Press GRAPH.

The calculator displays both the scatter plot and the least squares regression line.

The TI-84 can quickly compute and graph many of the statistical procedures introduced in this text, including:

  • one-variable summary statistics,
  • the five-number summary,
  • scatter plots,
  • Pearson's correlation coefficient, \(r\),
  • the coefficient of determination, \(R^2\),
  • least squares regression equations, and
  • regression graphs.

Although the calculator performs these computations automatically, it remains important to understand the underlying statistical concepts in order to interpret the results correctly.

Menu names and keystrokes may vary slightly by calculator model or operating-system version.
