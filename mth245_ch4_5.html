Chapter 4: Pictures of Data

Section 4.5: Stem-and-Leaf Graphs

Definition: Stem-and-Leaf Plot

A stem-and-leaf plot is a method for organizing numerical data while preserving the original values. It separates each data value into two parts: the stem, which contains the leading digit(s), and the leaf, which contains the final digit.

A stem-and-leaf plot helps display the shape of a data distribution, including the center, spread, clusters, gaps, and possible outliers.

For example, consider the following test scores:

\[62,\ 65,\ 67,\ 71,\ 73,\ 73,\ 76,\ 81,\ 84,\ 88,\ 92,\ 95\]

Using the tens digit as the stem and the ones digit as the leaf:

Stem-and-leaf plot of 12 test scores
StemLeaf
62 5 7
71 3 3 6
81 4 8
92 5

Key: \(7|3=73\)

Interpretation:

  • There are 12 observations in the data set.
  • The lowest score is 62.
  • The highest score is 95.
  • Most scores are in the 70s and 80s.
  • The data are concentrated around the middle values with fewer observations at the extremes.

The overall shape of a stem-and-leaf plot can resemble a histogram turned on its side. Unlike a histogram, however, the stem-and-leaf plot preserves the individual observations.
