Chapter 1: Probability Theory

Section 1.4: Counting Techniques

Many probability problems begin with a simple question: How many possible outcomes are there?

Rather than listing every possible outcome, mathematicians use combinatorics, the mathematics of counting.

Combinatorial methods provide efficient techniques for determining the number of possible outcomes without omission or duplication. These methods form the foundation for many probability calculations.

The Fundamental Counting Principle

The Fundamental Counting Principle

Suppose a process consists of several stages. If there are \(n_1\) possible choices for the first stage, \(n_2\) possible choices for the second stage for each allowable first-stage choice, and so on, then the total number of possible outcomes is

\[n_1n_2\cdots n_k.\]

This result is known as the Fundamental Counting Principle.

Example 1

A restaurant offers

  • 4 sandwiches,
  • 3 side dishes,
  • 5 beverages.

How many different meals are possible?

Solution

The total number of meals is

\[4(3)(5)=60.\]

Therefore, 60 different meals are possible.

Factorial Notation

Many counting formulas involve the product of consecutive positive integers. The factorial function provides a convenient notation for these products.

Definition: Factorial

For any positive integer \(n\),

\[n!=n(n-1)(n-2)\cdots3\cdot2\cdot1.\]

By definition,

\[0!=1 \quad\text{and}\quad 1!=1.\]

Example 2

Evaluate each expression.

  1. \(5!\)
  2. \(8!\)
  3. \(\dfrac{7!}{5!}\)

Solution

\[5!=5(4)(3)(2)(1)=120\] \[8!=40320\] \[\frac{7!}{5!}=\frac{7\cdot6\cdot5!}{5!}=42.\]

Permutations of \(n\) Objects

Definition: Permutation

A permutation is an arrangement in which order is important.

If all \(n\) distinct objects are arranged, then

\[{}_nP_n=n!\]

since there are

\[n(n-1)(n-2)\cdots2(1)=n!\]

possible arrangements.

Example 3

How many ways can five students stand in a line?

Solution

\[{}_5P_5=5!=120.\]

Permutations of \(r\) Objects

Permutations of \(r\) Objects

Suppose only \(r\) objects are selected from \(n\) distinct objects and order matters.

The number of possible arrangements is

\[{}_nP_r=\frac{n!}{(n-r)!}.\]

Example 4

Eight runners compete for first, second, and third place. Determine the number of possible finishes.

Solution

\[{}_8P_3=\frac{8!}{5!}=8(7)(6)=336.\]

Permutations with Repeated Objects

When identical objects occur, exchanging identical objects does not produce a new arrangement.

Permutations with Repeated Objects

If \(n\) objects contain

\[n_1,n_2,\ldots,n_k\]

identical objects of various types, then the number of distinct arrangements is

\[\frac{n!}{n_1!n_2!\cdots n_k!}\]

Example 5

Determine the number of distinct arrangements of the letters in

\[\text{STATISTICS}.\]

Solution

STATISTICS contains 10 letters: 3 S's, 3 T's, 2 I's, 1 A, and 1 C.

Therefore,

\[\frac{10!}{3!3!2!}=50400.\]

Combinations

Definition: Combination

A combination is a selection in which order is not important.

The number of ways to choose \(r\) objects from \(n\) distinct objects is

\[{}_nC_r=\binom{n}{r}=\frac{n!}{r!(n-r)!}.\]

Notice that there are two common notations for representing combinations: \({}_{n}C_{r}\) and \(\binom{n}{r}\).

Example 6

A committee of four students is selected from ten students. Determine the number of possible committees.

Solution

\[\binom{10}{4}=\frac{10!}{4!6!}=210.\]

Permutations versus Combinations

A useful question to ask is, does changing the order produce a different outcome?

If the answer is

  • Yes, use a permutation.
  • No, use a combination.

Pascal's Triangle

A useful tool for computing combinations is Pascal's Triangle. This is a simple numerical pattern that generates every combination without directly using the combination formula.

The triangle begins with a single 1. Each subsequent row begins and ends with 1, and every interior entry is obtained by adding the two entries directly above it.

\[ \begin{array}{ccccccccccccc} &&&&&&1\\[2mm] &&&&&1&&1\\[2mm] &&&&1&&2&&1\\[2mm] &&&1&&3&&3&&1\\[2mm] &&1&&4&&6&&4&&1\\[2mm] &1&&5&&10&&10&&5&&1\\[2mm] 1&&6&&15&&20&&15&&6&&1 \end{array} \]

For example,

\[6=3+3,\qquad 10=4+6,\qquad 20=10+10.\]

Thus, every interior number is the sum of the two numbers immediately above it.

Relationship to Combinations

Each row of Pascal's Triangle contains the combinations for a fixed value of \(n\). Specifically, if the top row is numbered 0, then \({}_{n}C_{r}\) is the \((r+1)\)st entry of row \(n\).

For example, the row

\[1\qquad5\qquad10\qquad10\qquad5\qquad1\]

corresponds to

\[ {}_{5}C_{0},\; {}_{5}C_{1},\; {}_{5}C_{2},\; {}_{5}C_{3},\; {}_{5}C_{4},\; {}_{5}C_{5}. \]

Evaluating each combination,

\[ \begin{aligned} {}_{5}C_{0} &=1,\\ {}_{5}C_{1} &=5,\\ {}_{5}C_{2} &=10,\\ {}_{5}C_{3} &=10,\\ {}_{5}C_{4} &=5,\\ {}_{5}C_{5} &=1. \end{aligned} \]

Notice that these values exactly match the entries in Pascal's Triangle.

Relationship to Permutations

Recall that the permutation formula is

\[{}_nP_r=\frac{n!}{(n-r)!},\]

while the combination formula is

\[{}_nC_r=\frac{n!}{r!(n-r)!}.\]

Comparing these formulas shows that

\[{}_nP_r=r!\,{}_{n}C_{r}.\]

Thus, a permutation can be viewed as a two-step process:

  1. Select \(r\) objects from \(n\) objects.
  2. Arrange the selected objects in every possible order.

Since there are \({}_{n}C_{r}\) ways to select the objects and \(r!\) ways to arrange them,

\[{}_nP_r=r!\,{}_{n}C_{r}.\]

Example 7

How many ways can three officers (president, vice president, and secretary) be chosen from eight students?

Solution

Method 1:

Use permutations.

\[{}_8P_3=\frac{8!}{5!}=336.\]

Method 2:

First choose three students.

\[{}_{8}C_{3}=56.\]

Next arrange the three officers.

\[3!=6.\]

Therefore,

\[56(6)=336.\]

Both methods produce the same answer.

Questions to Ask When Solving a Counting Problem

  1. Is the process completed in several stages? If so, consider the Fundamental Counting Principle.
  2. Are all objects being arranged? If so, use \(\mathbf{{}_nP_n=n!}\).
  3. Are only \(r\) objects being arranged? If so, use \(\mathbf{{}_nP_r}\).
  4. Are some objects identical? If so, use the formula for permutations with repeated objects.
  5. Does the order of the selected objects matter?
    • If yes, use a permutation.
    • If no, use a combination.
  6. Pascal's Triangle provides a convenient method for determining combinations as well as permutations using \({}_{n}P_{r}=r! \cdot {}_{n}C_{r}\).
