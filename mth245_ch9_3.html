Chapter 9: Hypothesis Testing

Section 9.3: General Steps of Hypothesis Testing

The General Steps

  1. State the claim and express it as a statistical hypothesis.
  2. State the competing hypothesis.
  3. State \(H_0\) and \(H_1\). The null hypothesis contains the equality component (\(=\), \(\leq\), or \(\geq\)); the alternative contains the corresponding strict inequality (\(\neq\), \(<\), or \(>\)).
  4. Select the significance level, \(\alpha\).
  5. Identify the appropriate test statistic and verify that the conditions for the test are satisfied.
  6. Compute the test statistic.
  7. Determine the critical value(s) (traditional method) or the \(p\)-value (\(p\)-value method). A sketch may help.
  8. Decide whether to reject or fail to reject \(H_0\).
  9. State the conclusion in context of the original problem.

Traditional (Critical Value) Method

The traditional method compares the test statistic with one or more critical values.

To determine the critical value(s), we analyze the type of test (left-, right-, or two-tailed) and the significance level (\(\alpha\)).

  • If we are conducting a two-tailed test, the Type I error identified by \(\alpha\) is split evenly between the right and left tails. We can go to the normal table and find the test statistics (\(z_c\) or \(t_c\)) by finding the values of \(\alpha/2\) and \(1-\alpha/2\) on the inside of the table and looking up the values in the column and row. These values will be the same magnitude and opposite sign.
  • If we are conducting a left-tailed test, the Type I error identified by \(\alpha\) is found entirely in the left tail. We can go to the normal table and find the test statistic (\(z_c\) or \(t_c\)) by finding the value of \(\alpha\) on the inside of the table and looking up the values in the column and row. The value will be negative.
  • If we are conducting a right-tailed test, the Type I error identified by \(\alpha\) is found entirely in the right tail. We can go to the normal table and find the test statistic (\(z_c\) or \(t_c\)) by finding the value of \(1-\alpha\) on the inside of the table and looking up the values in the column and row. The value will be positive.

Although going to the normal table will always work for \(z_c\), the most common values can be found in the following table:

Common critical values for z tests
Level of Significance\(1\%\)\(5\%\)\(10\%\)
Critical value \(z_\alpha\) for a left-tailed test\(-2.33\)\(-1.645\)\(-1.28\)
Critical value \(z_\alpha\) for a right-tailed test\(2.33\)\(1.645\)\(1.28\)
Critical value \(z_{\alpha/2}\) for a two-tailed test\(\pm 2.58\)\(\pm 1.96\)\(\pm 1.645\)

For \(t_c\), we always have to go to the table because of the degrees of freedom.

Decision Rule: Traditional Method

  • Reject \(H_0\) if the test statistic falls in the rejection region (the tails).
  • Otherwise fail to reject \(H_0\).

For example, if we have a two-tailed test with \(\alpha=0.05\), the critical values are \(\pm1.96\). If \(z=2.30\), then \(2.30>1.96\) and the null hypothesis is rejected.

\(P\)-value Method

Definition: \(p\)-value

The \(p\)-value is the probability, assuming \(H_0\) is true, of obtaining a test statistic at least as extreme as the observed test statistic in the direction specified by \(H_1\).

Decision Rule: \(p\)-value Method

  • Reject \(H_0\) if \(p\leq\alpha\).
  • Fail to reject \(H_0\) if \(p>\alpha\).

For example, if \(p=0.018\) and \(\alpha=0.05\), then \(0.018<0.05\) and the null hypothesis is rejected.
