Chapter 2: Binomial Probability Distribution

Section 2.4: Using Binomial Probability Tables

The binomial probability formula

\[P(X=x)=\binom{n}{x}p^xq^{n-x}\]

can be used to find any individual binomial probability. However, when many probabilities are needed, a binomial probability table provides a convenient alternative.

The binomial tables in this text list the individual probabilities

\[P(X=x)\]

for different values of the number of trials \(n\) and probability of success \(p\).

Each entry in the table represents the probability of obtaining exactly \(x\) successes. This works well in that the results of our formulas can be found in the table.

Other textbooks may use binomial tables that list the cumulative probability

\[P(X\le x),\]

rather than the probability of a single value. It is important to identify which type of table you are using.

Reading a Binomial Probability Table

A binomial probability table is organized by:

  • \(n\): the number of trials,
  • \(p\): the probability of success on each trial,
  • \(x\): the number of successes.

To Use the Table

  1. Locate the section of the table for the desired number of trials, \(n\), in the first column.
  2. Locate the desired probability of success, \(p\), across the first row.
  3. Find the row corresponding to the desired number of successes, \(x\), in the second column.
  4. Read the value of \(P(X=x)\).

The table used in this textbook gives individual probabilities \(P(X=x)\), not cumulative probabilities \(P(X\leq x)\).

Example 1

Suppose

\[X\sim\text{Bin}(10,0.40).\]

Use a binomial probability table to find

\[P(X=3).\]

\[P(X=2\text{ or }X=3)\]

\[P(X=2\text{ or }X=3)=P(X=2)+P(X=3)=0.1209+0.2150=0.3759\]

Example 2

A basketball player makes a free throw with probability \(0.80\). If the player attempts six free throws, find the probability of making

  • exactly five shots,
  • at least one shot,
  • more than four shots,
  • strictly between one and five shots.

Solution

Locate the section of the table for the desired number of trials for \(n=6\). Below is a portion of the correct table:

We then located the desired probability of success, \(p=0.8\), across the first row (highlighted). Then we read the appropriate values based on \(r\).

  • Exactly five shots: \(P(X=5)=0.3932\).
  • At least one shot: \(P(X\geq 1)=1-0.0001=0.9999\), or
  • At least one shot: \(P(X\geq 1)=0.0015+0.0154+0.0819+0.2458+0.3932=0.9999\).
  • More than four shots: \(P(X>4)=0.3932+0.2621=0.6553\).
  • Between one and five shots: \(P(1<X<5)=0.0154+0.0819+0.2458=0.3431\).

Comparing these values with those found in prior sections, we can see that they are basically the same. In some cases, we will see a small difference in the last digit we save due to rounding errors.

Summary of Binomial Table Calculations

How to find each type of probability from a binomial table
ProbabilityCalculation
\(P(X=x)\)Read directly from table
\(P(X\le x)\)\(P(0)+P(1)+\cdots+P(x)\)
\(P(X<x)\)\(P(0)+P(1)+\cdots+P(x-1)\)
\(P(X\ge x)\)\(P(x)+P(x+1)+\cdots+P(n)\)
\(P(X>x)\)\(P(x+1)+P(x+2)+\cdots+P(n)\)
\(P(a\le X\le b)\)\(P(a)+P(a+1)+\cdots+P(b)\)

Key Ideas

A binomial probability table provides individual values of

\[P(X=x).\]

To solve more complicated probability questions:

  • add probabilities for mutually exclusive outcomes,
  • use the complement rule when it reduces the number of calculations,
  • carefully translate phrases such as “at most,” “at least,” and “between” into mathematical notation.

The use of binomial tables reinforces the relationship between individual probabilities and the complete binomial probability distribution.
