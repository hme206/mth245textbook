Appendix A: Technology

Section A.4: Desmos

Desmos is a free, web-based graphing calculator that includes powerful tools for statistics and regression. It can quickly generate tables, scatter plots, regression models, and summary statistics, making it an excellent companion for learning introductory statistics.

Entering Data

To enter data:

  1. Open the Desmos Graphing Calculator.
  2. Click the + button and select Table, or click an empty expression line and type table.
  3. Enter the explanatory variable values in the first column (x1).
  4. Enter the response variable values in the second column (y1).

As the data are entered, Desmos automatically displays a scatter plot.

Summary Statistics

For a single variable stored in x1, Desmos can compute common summary statistics by entering expressions such as

mean(x_1), median(x_1), stdev(x_1), stdevp(x_1), quartile(x_1,1), quartile(x_1,3),

or min(x_1) and max(x_1).

These commands provide the quantities needed to compute measures of center, spread, and the five-number summary.

Regression

To fit a least squares regression line, enter the expression

y_1 ~ m x_1 + b

The symbol “~” (tilde) tells Desmos to perform a regression rather than graph an equation.

Desmos computes and displays the values of \(m\) (the slope) and \(b\) (the intercept), giving the regression equation

\[\hat y=mx+b.\]

The regression line is automatically drawn on the scatter plot.

After performing the regression, Desmos displays the coefficient of determination, \(R^2\), which represents the proportion of the variability in the response variable accounted for by the fitted linear model.

Once the regression equation has been computed, predicted values can be found by evaluating \(mx+b\) for any desired value of \(x\). Additional functions may also be defined to evaluate the regression equation at specific points.

Because the graphs update instantly as data are edited, Desmos is particularly useful for exploring how changes in the data affect the regression line and the strength of the linear relationship.

No matter which technology is used, the goal remains the same: to understand the data, interpret the results correctly, and communicate meaningful conclusions. Technology is an essential tool for modern statistics, but statistical thinking—not button pressing—is what transforms numerical output into useful information.
