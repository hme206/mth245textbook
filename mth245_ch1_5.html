Chapter 1: Probability Theory

Section 1.5: Summary

Probability is the study of uncertainty and measures how likely an event is to occur. Probabilities range from 0 to 1, with 0 meaning impossible and 1 meaning certain. A sample space contains all possible outcomes, while an event is a collection of outcomes.

Compound events involve multiple events. The union means “or,” while the intersection means “and.” Venn diagrams and tree diagrams help visualize these relationships. The addition rule is used for unions, and conditional probability describes the probability of one event given another.

Events can be mutually exclusive or independent. Mutually exclusive events cannot happen at the same time, while independent events do not affect each other. Multiplication rules are used to find the probability that events occur together, especially when dealing with dependent or independent events.

Counting techniques help determine how many possible outcomes exist. The Fundamental Counting Principle multiplies the number of choices at each stage. Factorials, permutations, and combinations are also important: permutations are used when order matters, while combinations are used when order does not matter.

Together, these ideas provide the basic tools needed to calculate probabilities, analyze compound events, and solve counting problems.
