Section 4.7: Exercises

The following exercises review the major concepts introduced in this chapter. Show your work and simplify answers when appropriate. References such as “Problem 9” refer to the problem with that number in the same group.

Frequency Distributions

  1. What is the primary purpose of frequency distributions and graphical displays?
  2. Explain why a graph that is constructed correctly can still give a misleading impression about a population.
  3. Identify whether each variable would generally be displayed using categorical or quantitative data:
    1. Favorite color
    2. Height
    3. Number of siblings
    4. Type of automobile
  4. Construct a frequency distribution for the following data: \[2,\;3,\;3,\;4,\;4,\;4,\;5,\;5,\;6,\;7.\]
  5. The following are the numbers of goals scored in 15 soccer games: \[0,\;1,\;2,\;1,\;3,\;2,\;0,\;4,\;2,\;1,\;3,\;2,\;1,\;0,\;2.\] Construct a frequency distribution.
  6. For the data \[12,\;15,\;17,\;18,\;21,\;24,\;25,\;27,\;30,\;31,\] find the minimum, maximum, and range.
  7. A data set has minimum value 14 and maximum value 86. Six classes are desired. Find the approximate class width and round upward.
  8. A grouped distribution uses the following class limits: 10–19, 20–29, 30–39, 40–49. Find the class boundaries for these classes assuming the observations are measured to the nearest whole number.
  9. A frequency distribution has the following frequencies:
    Frequencies for Problem 9
    Class12345
    Frequency47964
    Find the total number of observations.
  10. Using the distribution in Problem 9, calculate the relative frequency of each class.
  11. Using the distribution in Problem 9, calculate the cumulative frequencies.
  12. Using the distribution in Problem 9, calculate the cumulative relative frequencies.
  13. A class contains 8 observations out of a total of 40. Find its relative frequency as a decimal and percentage.
  14. A frequency distribution contains 50 observations. The first four classes have frequencies \[7,\;11,\;15,\;9.\] Find the frequency of the fifth class.
  15. Explain the difference between frequency, relative frequency, cumulative frequency, and cumulative relative frequency.
