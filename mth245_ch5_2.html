Chapter 5: Measures of Center and Spread

Section 5.2: Measures of Center

Mode

Definition: Mode

The mode of a data set is the value that occurs more often than any other value. Unlike the mean or median, the mode depends only on the frequency of each value, not on the numerical size of the values.

A data set may have:

  • One mode (unimodal),
  • Two modes (bimodal),
  • More than two modes (multimodal), or
  • No mode if every value occurs the same number of times. Under the convention used in this text, a data set has no mode when no value occurs more frequently than the others.

Different textbooks use slightly different conventions for the term mode when no value occurs more frequently than another.

Example 1

Consider the following set of test scores:

\[80,\ 89,\ 73,\ 95,\ 82,\ 65,\ 93,\ 94,\ 74,\ 84,\ 98,\ 86,\ 78,\ 82,\ 57,\ 92,\ 89,\ 84,\ 91,\ 72,\ 88,\ 79,\ 87,\ 90\]

Find the mode(s) and classify the data set.

Solution

To find the mode we need to count the frequency of each value. One method is to sort the values from smallest to largest:

\[57,\ 65,\ 72,\ 73,\ 74,\ 78,\ 79,\ 80,\ 82,\ 82,\ 84,\ 84,\ 86,\ 87,\ 88,\ 89,\ 89,\ 90,\ 91,\ 92,\ 93,\ 94,\ 95,\ 98\]

We can now look through the sorted data set to find the values with higher frequencies. The values 82, 84, and 89 each occur twice, while every other value occurs only once. The modes of this data set are 82, 84, and 89. Since three values are tied for the greatest frequency, this data set is multimodal.

Example 2

Consider the following set of test scores:

\[82,\ 83,\ 78,\ 87,\ 72,\ 89,\ 87,\ 74,\ 92,\ 75,\ 93,\ 82,\ 82,\ 78,\ 91\]

Find the mode(s) and classify the data set.

Solution

Sorting this data set yields:

\[72,\ 74,\ 75,\ 78,\ 78,\ 82,\ 82,\ 82,\ 83,\ 87,\ 87,\ 89,\ 91,\ 92,\ 93\]

The value 82 appears three times, more than any other value. The mode of this data set is 82. Since only one value has the greatest frequency, this data set is unimodal.

Key Points

  • The mode is the value that appears most frequently in a data set.
  • A data set can have one mode, more than one mode, or no mode.
  • Data sets can be unimodal, bimodal, multimodal, or have no mode.
  • The mode is the only common measure of center that can be used with nominal categorical data.

Median

Definition: Median

The median is a measure of the center of a data set. It is the middle value when the observations are arranged in order from smallest to largest. Because the median depends only on the order of the observations, it is much less affected by unusually large or unusually small values than the arithmetic mean.

When dealing with the entire population, the population median is often denoted by \(\tilde{\mu}\). When dealing with a sample, the sample median is often denoted by \(\tilde{x}\).

To Find the Median

  1. Arrange the observations in ascending order.
  2. If the number of observations, \(n\), is odd, the median is the middle observation.
  3. If \(n\) is even, the median is the average of the two middle observations.

Example 3

Find the median of the following set of test scores:

\[80,\ 89,\ 73,\ 95,\ 82,\ 65,\ 93,\ 94,\ 74,\ 84,\ 98,\ 86,\ 78,\ 82,\ 57,\ 92,\ 89,\ 84,\ 91,\ 72,\ 88,\ 79,\ 87,\ 90\]

Solution

First, arrange the observations in ascending order:

\[57,\ 65,\ 72,\ 73,\ 74,\ 78,\ 79,\ 80,\ 82,\ 82,\ 84,\ 84,\ 86,\ 87,\ 88,\ 89,\ 89,\ 90,\ 91,\ 92,\ 93,\ 94,\ 95,\ 98\]

There are

\[n=24\]

observations, so the median is the average of the 12th and 13th observations.

\[ \begin{aligned} x_{(12)} &= 84,\\ x_{(13)} &= 86. \end{aligned} \]

Therefore,

\[\tilde{x}=\frac{84+86}{2}=85.\]

Thus,

\[\tilde{x}=85.\]

Example 4

Find the median of the following set of test scores:

\[82,\ 83,\ 78,\ 87,\ 72,\ 89,\ 87,\ 74,\ 92,\ 75,\ 93,\ 82,\ 82,\ 78,\ 91\]

Solution

Arrange the observations in ascending order:

\[72,\ 74,\ 75,\ 78,\ 78,\ 82,\ 82,\ 82,\ 83,\ 87,\ 87,\ 89,\ 91,\ 92,\ 93.\]

There are

\[n=15\]

observations, so the median is the middle (8th) observation.

\[x_{(8)}=82.\]

Therefore,

\[\tilde{x}=82.\]

Interpreting the Median

The median is a value such that approximately half the observations are at or below it and approximately half are at or above it.

Unlike the arithmetic mean, the median is resistant to unusually large or unusually small observations. For this reason, the median is often preferred when a data set contains outliers or is strongly skewed.

Key Points

  • The median is the middle value of an ordered data set.
  • If the number of observations is odd, the median is the middle observation.
  • If the number of observations is even, the median is the average of the two middle observations.
  • The median is resistant to extreme observations and is therefore less sensitive to outliers than the arithmetic mean.

Mean

Definition: Arithmetic Mean

The mean is a measure of the center of a data set. When people refer to the “average” of a set of numbers, they are almost always referring to the arithmetic mean. The arithmetic mean is found by adding all of the observations and dividing by the number of observations.

If a data set consists of the values

\[x_1,x_2,\ldots,x_n,\]

then the arithmetic mean is

\[\bar{x}=\frac{x_1+x_2+\cdots+x_n}{n}=\frac{\displaystyle\sum_{i=1}^{n}x_i}{n},\]

where \(n\) is the number of observations.

The arithmetic mean uses every value in the data set, making it one of the most widely used measures of center. However, because every value contributes to the calculation, unusually large or unusually small observations (outliers) can have a substantial effect on the mean.

Although the arithmetic mean is the most common, other types of means are used in specialized applications. The geometric mean is appropriate for quantities that change by multiplication, such as investment returns or population growth. The harmonic mean is useful for averaging rates, such as speeds or unit costs. Unless otherwise stated, the word mean refers to the arithmetic mean.

Example 5

Find the arithmetic mean of the following set of test scores:

\[80,\ 89,\ 73,\ 95,\ 82,\ 65,\ 93,\ 94,\ 74,\ 84,\ 98,\ 86,\ 78,\ 82,\ 57,\ 92,\ 89,\ 84,\ 91,\ 72,\ 88,\ 79,\ 87,\ 90\]

Solution

There are \(n=24\) observations.

The sum of the observations is

\[80+89+73+\cdots+90=2002.\]

Therefore, the arithmetic mean is

\[\bar{x}=\frac{2002}{24}\approx 83.4167.\]

Thus, the average value in this data set is approximately

\[\bar{x}\approx 83.42.\]

The arithmetic mean can be thought of as the “balance point” of a data set. If the total of all observations were distributed equally among all observations, each value would equal the mean. The balance-point interpretation applies to the arithmetic mean: the sum of the deviations from the mean is zero.

\[\sum_{i=1}^{n}(x_i-\bar{x})=0\]

Notice that the mean does not have to be one of the values in the data set. In this data set, the mean is approximately \(83.42\), even though no observation has that exact value.

Geometric and Harmonic Means

Definition: Geometric Mean

For a set of \(n\) positive numbers \(x_1,x_2,\ldots,x_n\), the geometric mean is

\[G=\sqrt[n]{x_1x_2\cdots x_n}.\]

Definition: Harmonic Mean

For a set of \(n\) positive numbers \(x_1,x_2,\ldots,x_n\), the harmonic mean is

\[H=\frac{n}{\displaystyle\sum_{i=1}^{n}\frac{1}{x_i}}.\]

Example 6

Find the arithmetic mean, geometric mean, and harmonic mean of the data set

\[\{1,2,3,4\}.\]

Solution

The sum of the observations is

\[1+2+3+4=10\]

Since there are four observations,

\[\bar{x}=\frac{10}{4}= 2.5.\]

Thus, the arithmetic mean, or average, is

\[\bar{x}=2.5.\]

The product of the observations is

\[1\cdot2\cdot3\cdot4=24.\]

Since there are four observations,

\[G=\sqrt[4]{24}\approx2.213.\]

Therefore, the geometric mean is approximately

\[G\approx2.213.\]

The sum of the reciprocals is

\[1+\frac12+\frac13+\frac14=\frac{25}{12}.\]

Since there are four observations,

\[H=\frac{4}{25/12}=\frac{48}{25}=1.92.\]

Therefore, the harmonic mean is

\[H=1.92.\]

Comparison of the Three Means

For the small data set

\[\{1,2,3,4\},\]

the three common means are

\[ \begin{aligned} \text{Arithmetic mean} &= \frac{1+2+3+4}{4}=2.5,\\ \text{Geometric mean} &= \sqrt[4]{24}\approx2.213,\\ \text{Harmonic mean} &= \frac{48}{25}=1.92. \end{aligned} \]

For positive observations, the harmonic mean is less than or equal to the geometric mean, which is less than or equal to the arithmetic mean.

\[\text{Harmonic Mean}\le\text{Geometric Mean}\le\text{Arithmetic Mean}.\]

Equality occurs if and only if all observations are equal.

Key Points

  • The arithmetic mean is the sum of the observations divided by the number of observations.
  • It is the measure of center most commonly referred to as the “average.”
  • Every observation contributes to the calculation, so the mean is sensitive to unusually large or small values.
  • Other means, including the geometric mean and harmonic mean, are used for specialized applications involving multiplicative growth and rates, respectively.

Trimmed Mean

Definition: Trimmed Mean

The trimmed mean is a measure of center that reduces the influence of unusually small or unusually large observations. It is computed by removing a specified percentage of the smallest and largest values from a data set and then calculating the arithmetic mean of the remaining observations.

In this textbook, a \(p\%\) trimmed mean removes approximately \(p\%\) in total, divided approximately equally between the two tails. Trimming is particularly useful when a data set contains potential outliers that might distort the ordinary arithmetic mean.

For a data set with \(n\) observations, let

\[k=\frac{pn}{100},\]

where \(p\) is the trimming percentage. By removing \(k/2\) values from each end the result is a \(p\%\) trimmed mean. This convention is common in statistics, but not absolute. Some prefer to round to the nearest even integer.

After sorting the data, remove the smallest \(k/2\) observations and the largest \(k/2\) observations. The trimmed mean is then

\[\bar{x}_{\text{trim}}=\frac{\displaystyle\sum_{i=k/2+1}^{n-k/2}x_{(i)}}{n-k},\]

where \(x_{(1)}\le x_{(2)}\le\cdots\le x_{(n)}\) are the ordered observations.

Example 7

Find the \(10\%\) trimmed mean of the following set of test scores:

\[80,\ 89,\ 73,\ 95,\ 82,\ 65,\ 93,\ 94,\ 74,\ 84,\ 98,\ 86,\ 78,\ 82,\ 57,\ 92,\ 89,\ 84,\ 91,\ 72,\ 88,\ 79,\ 87,\ 90\]

Solution

There are

\[n=24\]

observations. For a \(10\%\) trimmed mean,

\[k=0.10(24)=2.4\approx{2}.\]

Thus, we remove the smallest observation and the largest observation.

First, order the data from smallest to largest:

\[57,\ 65,\ 72,\ 73,\ 74,\ 78,\ 79,\ 80,\ 82,\ 82,\ 84,\ 84,\ 86,\ 87,\ 88,\ 89,\ 89,\ 90,\ 91,\ 92,\ 93,\ 94,\ 95,\ 98.\]

Remove the smallest value, \(57\), and the largest value, \(98\):

\[65,\ 72,\ 73,\ 74,\ 78,\ 79,\ 80,\ 82,\ 82,\ 84,\ 84,\ 86,\ 87,\ 88,\ 89,\ 89,\ 90,\ 91,\ 92,\ 93,\ 94,\ 95.\]

The sum of the trimmed data is

\[65+72+73+\cdots+95=1847.\]

Since \(22\) observations remain, the \(10\%\) trimmed mean is

\[\bar{x}_{\text{trim}}=\frac{1847}{22}\approx 83.95.\]

Therefore,

\[10\%\text{ trimmed mean} \approx 83.95.\]

Interpreting the Trimmed Mean

The ordinary arithmetic mean of this data set is

\[\bar{x}=\frac{2002}{24}\approx83.42,\]

while the \(10\%\) trimmed mean is

\[\bar{x}_{\text{trim}}=83.95.\]

The trimmed mean is slightly larger because the smallest observation (\(57\)) is farther below the center of the data than the largest observation (\(98\)) is above it. By removing one value from each end, the influence of these extreme observations is reduced.

Key Points

  • A trimmed mean is computed by removing the same percentage of observations from both ends of an ordered data set before calculating the arithmetic mean.
  • Trimming reduces the effect of unusually small or unusually large observations.

Weighted Mean

Definition: Weighted Mean

The weighted mean is a measure of center that assigns different levels of importance, or weights, to the observations in a data set. It is used when some observations should contribute more to the average than others.

If the observations are

\[x_1,x_2,\ldots,x_n,\]

with corresponding weights

\[w_1,w_2,\ldots,w_n,\]

then the weighted mean is

\[\bar{x}_w=\frac{\displaystyle\sum_{i=1}^{n}w_i x_i}{\displaystyle\sum_{i=1}^{n}w_i},\]

where the weights \(w_i\) are nonnegative numbers. If all of the weights are equal, the weighted mean is the ordinary arithmetic mean.

If the weights are proportions that sum to 1, then the weighted mean is

\[\bar{x}_w=\displaystyle\sum_{i=1}^{n}w_i \bar{x}_i.\]

The weighted mean is commonly used when observations represent different frequencies, levels of importance, or proportions. Examples include computing a course grade from weighted assignments, finding the average price paid for shares purchased at different prices, or averaging values measured over unequal intervals.

Example 8

Suppose a course grade is determined as follows:

Course grade weights
AssessmentWeight
Tests60%
Homework20%
Final Exam20%

A student takes

  • Four tests: 72, 97, 60, 85.
  • Four homework assignments: 37, 75, 59, 43.
  • One final exam: 65.

Find the weighted mean (the course grade).

Solution

The average for each group is:

\[\bar{x}_{\text{Tests}}=\frac{72+97+60+85}{4}=\frac{314}{4}=78.5.\] \[\bar{x}_{\text{HW}}=\frac{37+75+59+43}{4}=\frac{214}{4}=53.5.\] \[\bar{x}_{\text{Final}}=65.\]

The weighted mean is

\[\bar{x}_w=0.60(78.5)+0.20(53.5)+0.20(65)=70.8.\]

Therefore,

\[\bar{x}_w=70.8.\]

Key Points

  • A weighted mean assigns different levels of importance to different observations.
  • The weighted mean is computed by dividing the sum of the weighted observations by the sum of the weights.
  • If all weights are equal, the weighted mean is the ordinary arithmetic mean.
  • Weights may represent percentages, frequencies, probabilities, or relative importance.
  • The weighted mean is widely used in education, finance, economics, and the physical and social sciences.
