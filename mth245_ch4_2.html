Chapter 4: Pictures of Data

Section 4.2: Frequency Distributions

Raw data are often difficult to interpret, especially when many observations have been collected. One of the first steps in descriptive statistics is to organize the data into tables and graphs that summarize the important features of the data.

Frequency distributions organize data into meaningful categories or intervals, making patterns easier to recognize.

Definition: Frequency Distribution

A frequency distribution is a table that summarizes data by listing each category or class together with the number of observations that fall within that category.

Frequency distributions may be constructed for either categorical or numerical data.

Frequency Distributions for Categorical Data

For categorical data, each category is listed along with its frequency. It is common to include a tally column to help count the number in each group.

Example: The favorite school subject of 30 students is recorded.

In some cases, discrete quantitative data with a small number of values may also be treated in this manner. When a discrete variable has only a small number of possible values, each value can be treated as a separate category. For example, if we were analyzing the number of goals scored in professional soccer games, values of \(\{0, 1, 2, 3, 4, 5, \ldots\}\) would suffice.

Grouped Frequency Distributions

Definition: Classes

When numerical data contain many different values, observations are grouped into intervals called classes.

Each class contains a specified range of values, and the number of observations in each class is recorded.

Steps for Constructing a Grouped Frequency Distribution

  1. Determine the minimum and maximum values.
  2. Compute the range.
  3. Select the desired number of classes.
  4. Determine the class width.
  5. Construct the class limits.
  6. Count the observations in each class.

There is no single correct number of classes. In many introductory applications, between 5 and 10 classes provides a useful summary, but the appropriate number depends on the data and the purpose of the display.

Too few classes may hide important features of the data, while too many classes may obscure overall patterns.

Range and Class Width

The range of a data set is

\[\text{Range}=\text{Maximum}-\text{Minimum}.\]

The class width is approximately

\[\text{Class Width}=\frac{\text{Range}}{\text{Number of Classes}}\]

The result is usually rounded up to a convenient value.

Example 1

Suppose the smallest observation is 18 and the largest observation is 92. If six classes are desired, find a convenient class width.

Solution

The range is

\[\text{Range}=92-18=74.\]

The approximate class width is

\[\frac{74}{6}=12.33.\]

Rounding upward gives a convenient class width of

\[13.\]

Rounding the class width upward may cause the total span of the classes to exceed the observed range. This is acceptable as long as every observation belongs to exactly one class.

Class Limits and Class Boundaries

Definition: Class Limits

The class limits are the smallest and largest values that may belong to each class. The lower class limit is the smallest value that can belong to the class, and the upper class limit is the largest.

Definition: Class Boundaries

Class boundaries create adjacent, non-overlapping intervals with no gaps between classes.

For data measured to the nearest unit, the class 18–30 has boundaries 17.5–30.5. Similarly, the class 31–43 has boundaries 30.5–43.5.

Relative and Cumulative Frequency

Definition: Relative Frequency

The relative frequency of a class is the proportion (or percentage) of observations that fall within that class.

\[\text{Relative Frequency}=\frac{\text{Class Frequency}}{\text{Total Number of Observations}}\]

Relative frequencies always sum to 1 (or 100%). Relative frequency can be expressed as a decimal, fraction, or percentage.

Definition: Cumulative Frequency

The cumulative frequency for a class is obtained by adding the frequencies for that class and all preceding classes.

For an ordered quantitative distribution, the cumulative frequency tells us how many observations are at or below the upper boundary of a given class.

The final cumulative frequency always equals the total number of observations.

Definition: Cumulative Relative Frequency

The cumulative relative frequency is the running total of the relative frequencies.

For an ordered quantitative distribution, cumulative relative frequency represents the proportion of observations at or below a given class.

The final cumulative relative frequency is always 1 (or 100%).
